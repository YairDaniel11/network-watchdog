# רענון רשת אוטומטי (Network Watchdog)

אפליקציית אנדרואיד למכשירי מקשים ישנים (מינימום Android 4.4 / API 19),
עם שלושה כפתורים במסך הראשי:

1. **רענון רשת ידני** - לחיצה מעבירה את המכשיר למצב טיסה ל-3 שניות וחזרה,
   כדי לגרום לו לתפוס רשת מחדש.
2. **מעקב רשת טלפונית** - מפעיל/מכבה בדיקה תקופתית (כל 5 דקות) של רישום
   לרשת סלולרית. **רק אם אין רשת** - מבצע את אותו רענון אוטומטית.
3. **מעקב אינטרנט** - אותו רעיון, אבל בודק חיבור אינטרנט אמיתי (בקשת HTTP
   לשרת), לא רק "יש רשת רשומה". עצמאי לגמרי מהמעקב הטלפוני - אפשר להפעיל
   רק אחד מהם, שניהם, או אף אחד.

מעל הכפתורים מוצג חיווי האם למכשיר יש הרשאות רוט - **חובה שיהיו, אחרת
הרענון לא יעבוד**, כי החלפת מצב טיסה בלי אינטראקציה של המשתמש דורשת
הרשאת מערכת (`su`).

## למה זה קל ל-RAM ולסוללה

- אין Service שרץ ברצף ברקע. הבדיקה התקופתית מתוזמנת עם `AlarmManager`
  (`setInexactRepeating`, ראו `AlarmScheduler.java`) - המערכת מעירה את
  `NetworkCheckReceiver` לכמה שניות כל 5 דקות ואז חוזרת לישון לגמרי.
- הרענון בפועל (מצב טיסה) קורה **רק אם אין רשת בפועל** - לא בכל מחזור,
  בניגוד לגרסה הקודמת שהוזכרה.
- `targetSdk 34` + `minSdk 19` יחד (ראו `app/build.gradle`) - זה מה שמונע
  את דיאלוג "האפליקציה נבנתה לגרסה ישנה ועלולה שלא לעבוד כראוי" במכשירים
  חדשים, בלי לוותר על תמיכה במכשיר הישן.
- אין תלות ב-AndroidX/AppCompat, כדי לשמור על טביעת רגל זיכרון מינימלית.

## בנייה

הקוד נבנה אוטומטית ב-GitHub Actions בכל `push` לענף `main`/`master`
(ראו `.github/workflows/build.yml`) - ה-APK מופיע גם כ-Artifact זמני
וגם כ-GitHub Release קבוע בעמוד "Releases" של המאגר.

לבנייה מקומית (אם מותקן Android Studio / SDK): לפתוח את התיקייה כפרויקט
ולהריץ `assembleDebug`.

## חשוב לדעת

- ללא הרשאות רוט על המכשיר, שום כפתור באפליקציה לא יצליח לרענן רשת -
  זה לא באג, זו מגבלת המערכת (Android חוסם שינוי מצב טיסה תכנותי בלי
  הרשאת מערכת).
- מעקב רשת טלפונית דורש הרשאת "קרא מצב טלפון" (`READ_PHONE_STATE`) -
  האפליקציה מבקשת אותה בזמן הפעלת המתג הראשונה.
