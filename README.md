# רענון רשת אוטומטי (Network Watchdog)

אפליקציית אנדרואיד למכשירי מקשים ישנים (מינימום Android 4.4 / API 19).

## מסך ראשי
1. **רענן רשת עכשיו** - מצב טיסה ל-3 שניות וחזרה.
2. **שורת סטטוס רוט** - האם יש הרשאות רוט (חובה, אחרת שום רענון לא יעבוד).
3. **הגדרות** - פותח את מסך ההגדרות.

## מסך הגדרות
- **מעקב רשת טלפונית / מעקב אינטרנט** - כל אחד עצמאי, בודק כל 5 דקות,
  ומרענן **רק אם אין רשת בפועל**. כולל טיפול במצב שבו המכשיר כבר במצב
  טיסה (למשל הופעל ידנית) - המעקב יוציא אותו מזה, לא רק "יהבהב".
- **התרעה כשאין קליטה** / **התרעה כשחוזרת הקליטה** - כל אחת בנפרד: הפעלה,
  בחירת צליל מתוך המכשיר (בורר הצלילים הרגיל של אנדרואיד), ובחירת מצב
  (צליל+רטט / צליל בלבד / רטט בלבד). ההתרעה מופעלת פעם אחת בכל מעבר מצב
  (ירידה/חזרה), לא בכל בדיקה.

## תיקוני אמינות (למקרה שהמעקב "לא עובד")
- הבדיקה התקופתית עברה מ-`setInexactRepeating` ל-`setExactAndAllowWhileIdle`
  עם שרשור עצמי (כל בדיקה מתזמנת את הבאה) - הרבה יותר אמין תחת Doze/App
  Standby באנדרואיד מודרני.
- כשמפעילים מעקב כלשהו, האפליקציה גם מעניקה לעצמה בשקט (דרך רוט, בלי
  דיאלוג) הרשאת "אלארמים מדויקים" ופטור מחיסכון סוללה - שתי הרשאות
  שבד"כ דורשות אישור ידני של המשתמש דרך הגדרות המערכת.
- בדיקת מצב הטיסה עצמו נעשית ישירות מול `Settings.Global.AIRPLANE_MODE_ON`,
  לא רק דרך היסק ממצב הטלפון - זה מה שפותר את התרחיש של מצב טיסה ידני
  שנשאר תקוע.

## עיצוב ואייקון
העיצוב (רקע כהה, אקסנט טורקיז) לקוח מאפליקציית הבייביסיטר הטלפוני שלך.
המבנה (כפתור רענון + סטטוס + הגדרות, ScrollView בכל מסך) נלמד מהמבנה של
האפליקציה הראשונית שלך (`com.example.airplanerefresh`) - כולל תיקון
הבאג שבו לא ניתן היה לגלול למטה במסכים ארוכים במכשיר מקשים.
האייקון הוחלף לאייקון שסיפקת (עיגול תכלת עם WiFi + חצי רענון).

## בנייה
נבנה אוטומטית ב-GitHub Actions בכל push (ראו `.github/workflows/build.yml`) -
ה-APK מופיע כ-Artifact וגם כ-GitHub Release.

## חשוב לדעת
- ללא הרשאות רוט, שום כפתור לא יצליח לרענן רשת - זו מגבלת מערכת, לא באג.
- מעקב רשת טלפונית דורש הרשאת "קרא מצב טלפון" - נשאלת בהפעלה הראשונה.
